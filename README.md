# Nebula – Planificador de Tareas

## Descripción del proyecto

Nebula es un planificador de tareas web diseñado para ayudar a organizar actividades, administrar pendientes y hacer seguimiento a su progreso de una manera sencilla e interactiva.

El proyecto cuenta con una interfaz desarrollada con HTML, CSS y Bootstrap, y funcionalidades implementadas con JavaScript, como la creación, validación, visualización y gestión de tareas.

Su diseño está inspirado en un universo galáctico, acompañado de una mascota virtual que aporta una experiencia más amigable.
